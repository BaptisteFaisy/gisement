Motivation introduces the concepts of diskless topics. This KIP describes the core functionality of diskless topics, such as the produce and consume paths. Glossary Diskless Topic:A topic which does not append directly to block storage devices, and does not utilize direct replication. Classic Topic:A topic which appends directly to block storage devices and utilizes direct replication, the present Kafka status quo. Tiered Topic:A classic topic using KIP-405 Tiered Storage to move inactive segments off of block storage, but still appends to block storage devices. Hybrid Topic: A topic which has portions of the log stored under both Classic and Diskless mechanisms. Diskless-Ready Cluster:An Apache Kafka cluster which is configured to host Diskless Topics in addition to Classic and Tiered topics.
