Motivation In Apache Kafka 3.0,enabled the strongest message delivery guarantee for the producer by default by enabling idempotence and settingsacks=1. Notably, an equivalent change was not made for consumers. Isolation level controls how consumers read messages written transactionally. If the consumer is usingread_uncommittedisolation level, the consumer reads messages written transactionally whether they were aborted or written by transactions which are still open. If the consumer is usingread_committedisolation level, the consumer reads messages written transactionally only when they have been committed. Messages which were written outside transactions are read regardless of the isolation level.
