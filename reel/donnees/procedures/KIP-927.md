Motivation When running kafka-metadata-quorum script to get the quorum replication status, the LastFetchTimestamp and LastCaughtUpTimestamp output is not human-readable. It would be convenient to add an optional flag to enable a human-readable format showing the operation delay in ms (i.e. 366 ms ago). This delay is computed as (now - timestamp), where they are both represented as Unix time (UTC based).
