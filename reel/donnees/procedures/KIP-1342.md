## Objet

Status Current state: Under Discussion Discussion thread:https://lists.apache.org/thread/0frtc6h3y9ts89do3qb9yk6oj3o1ktg2 JIRA:KAFKA-18800 Target release: 4.5 Please keep the discussion on the mailing list rather than commenting on the wiki (wiki discussions get unwieldy fast). Motivation Authorizer#aclCount()was added byKIP-801(PR #11649, Kafka 3.2) so that the broker could publish anAclCountmetric by reading the value from the authorizer. The broker side of that plan was never implemented. KIP-877later introducedMonitorable/PluginMetrics, which lets every plugin register its own metrics. Authorizers gained that support in 4.1 (KAFKA-18888,PR #19050), andStandardAuthorizernow publishesacls-total-countthroughPluginMetrics, backed by exactly the same data asAuthorizer#aclCount(). WithPluginMetricsavailable,Authorizer#aclCount()no longer has a purpose, so this KIP deprecates it. Third-party authorizers that want an ACL-count metric, or any other metric, should implementMonitorableper KIP-877.
