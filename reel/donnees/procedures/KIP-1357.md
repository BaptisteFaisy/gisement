Motivation Kafka Streams supports custom task assignors in the classic client-side assignment model viatask.assignor.class.However,this customization does not carry over to the Streams Rebalance Protocol(KIP-1071),where task assignment is computed on the broker rather than in the client.As a result,users ofgroup.protocol=streamscannot provide a custom assignor implementation,even though a similar capability exists both in classic Streams and in KIP-848 consumer groups(viagroup.consumer.assignors). This KIP closes the feature gap by adding first-class broker-side custom task assignor support for streams groups.Specifically,it: Exposes the necessary public Java interfaces so that users can implement custom task assignors. Supports configuring assignors through a static broker configurationgroup.streams.assignorsthat accepts both built-in assignor short names and fully qualified class names of custom implementations.
