Summary KIP-1150 introduced diskless topics. KIP-1163 defines their produce, fetch, and replica behavior, and KIP-1164 defines the Diskless coordinator. Those KIPs use mixed-partition write-ahead log (WAL) objects as the durable ingest format and leave the transfer to KIP-405 Tiered Storage to a follow-up KIP. This KIP defines that transfer. Every diskless topic is a consolidated diskless topic (CDT) from creation. Producers write through the diskless WAL. Each assigned replica materializes the untiered suffix as ordinary per-partition Kafka log segments. The partition leader copies closed segments through the existing KIP-405 Remote Storage Manager (RSM) and Remote Log Metadata Manager (RLMM) interfaces.
