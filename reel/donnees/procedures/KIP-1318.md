MCP follows a client-host-server architecture where the host application (such as Claude Desktop or VS Code) creates one MCP client per MCP server connection, with all communication using JSON-RPC 2.0 messages through stateful sessions with capability negotiation at initialization. The protocol defines three server-side primitives: Tools- functions for the AI model to execute (state-changing actions) Resources- context and data for the model (read-only) Prompts- templated messages and workflows MCP was designed to solve the "N×M integration problem" where developers previously had to build custom connectors for each combination of data source and AI tool.
