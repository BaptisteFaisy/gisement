Motivation Named groups are how the JVM describes TLS key exchange schemes. APIs to use named groups have been added in Java 20. ViaJEP 527: Post-Quantum Hybrid Key Exchange for TLS 1.3, new key exchange schemes resistant to quantum attacks, usually referred to as Post Quantum Cryptography (PQC), are being introduced. This JEP was initially delivered in Java 27. It's being backported by several implementations to earlier Java versions. Note that theSSLParameters.setNamedGroups()API is available from Java 20, but the PQC named groups themselves (e.g.x25519_mlkem768) require Java 27 or a vendor backport that includes JEP 527. Due to threats like "harvest now, decrypt later", many organizations are now actively considering PQC TLS. It is also mandated by several governments and industries such as finance, healthcare and defense. Public Interfaces All communication channels that are encrypted via TLS need to support PQC.
