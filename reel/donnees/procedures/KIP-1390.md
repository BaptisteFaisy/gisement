Motivation KIP-768addedOAuthBearerValidatorCallbackHandler, so a broker can validate OAuth tokens from an OIDC provider. Some brokers only need this, because they use another security protocol or SASL mechanism for connections to other brokers and controllers. These brokers never need their own token. They only need the public keys from the OIDC provider to validate client tokens. In this KIP I call them validate-only brokers. However, the broker still runs a JAAS login for OAUTHBEARER at startup.OAuthBearerLoginModuleaccepts a login without a token, but Kafka has no dedicated login callback handler for this case. Whensasl.login.callback.handler.classis not set, the defaultOAuthBearerUnsecuredLoginCallbackHandleris used. It is an internal class for testing.
