Motivation KIP-1271added the ability topersist record headersinside Kafka Streams state stores. When a store is built with one of the newWithHeaderssuppliers/builders, the record's Headers are stored alongside the value, surfaced internally through the wrapper typesValueTimestampHeaders<V>(timestamped key/value and window stores) andAggregationWithHeaders<AGG>(session stores). However, that infrastructure deliberately doesnotexpose headers through Interactive Queries (IQv2): there is no query type whose result carries headers, so even against a header-aware store the stored headers cannot be read back.
