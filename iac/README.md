# IaC — Gisement (lot 21)

Reproducible deployment, no undocumented manual step (ENF-16).

```bash
cd iac
python3 -m pip install -r requirements.txt
cdk bootstrap          # once per account/region
cdk synth              # review the template
cdk deploy             # deploy to eu-west-3
```

Region `eu-west-3` (Paris), fallback `eu-central-1`. Serverless only: no
dedicated endpoint, no always-on SageMaker, no GPU (26.4).

## What the stack creates

| Resource | Purpose |
|---|---|
| S3 + CloudFront | the static portal (`portal/`), HTTPS only |
| Cognito user pool | the five roles of chapter 7, the DPO first-class |
| API Gateway + Lambda | the API; the handler is `gisement.lambdas.api`, the same pure handlers the local server runs |
| DynamoDB | campaigns, motifs, processes, deposits, projects, advised-against, follow-up; the **register** is append-only with point-in-time recovery |
| Step Functions | the campaign orchestration, capped at four hours (ENF-18) |
| S3 (corpus) | sanitised corpora and reports, encrypted, versioned, 180-day retention (ENF-06) |
| IAM | least privilege: Transcribe, Bedrock (InvokeModel, Retrieve, Data Automation), Comprehend, scoped to the region |

## Judge access

The demo is pre-loaded with the synthetic client. Judge credentials are issued
in the Cognito user pool; the portal reads the tenant from the token, never
from a parameter (EF-71), and every measure passes through the AgentCore Policy
before the tool runs (R5).

## Staying online (ENF-17)

The solution must stay up, free, until 22 January 2027. Everything is
serverless and scale-to-zero: Lambda, DynamoDB on-demand, Step Functions per
transition, CloudFront. No always-on compute. The corpus bucket retains 180
days then expires; the register is retained.

## Not in this stack

The AgentCore components (Runtime, Gateway, Identity, Policy, Memory,
Observability) and Amazon Quick are provisioned separately - AgentCore because
its Policy artefact is generated by `gisement.politique.agentcore` (decision
D-09) and applied at the gateway, Quick because the dashboard is built from the
asset bundle of `infra/quick/`. See `docs/RUNBOOK.md`.
